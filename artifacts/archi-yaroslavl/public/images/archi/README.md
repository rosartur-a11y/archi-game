# Спрайты ARCHI

Игровые спрайты ARCHI для четырёх стадий пути. Фон у персонажей вырезан
(прозрачный PNG), поэтому в игре ARCHI выглядит как спрайт мобильной игры,
а не как «квадратная фотография» внутри рамки.

- `level-01.png` — «Новичок», уровень 1+
- `level-10.png` — «Развитие», уровень 10+
- `level-20.png` — «Успешный», уровень 20+
- `level-30.png` — «Легенда», уровень 30+

Исходники — непрозрачные кадры из файла
`A486BF40-A4CF-47A9-95B2-C52D82DA1135.png` (ряд «СТИЛИ ПЕРСОНАЖА»). 
Прозрачные версии генерируются ML-скриптом `tools/cutout-bg.py`
(rembg/u2net, альфа-маттинг кромки):

    PYTHONPATH=/tmp/rembg U2NET_HOME=/tmp/u2net python3 tools/cutout-bg.py

`tools/make-sprites.mjs` — резервный flood-fill метод + диагностика
(превью силуэтов, статистика маски). Он НИКОГДА не перезаписывает
оригинальные `level-*.png` — только пишет `*.sprite.png`.
Оригинальные кадры можно восстановить из git.

`ArchiCharacter` выбирает спрайт по порогам уровня 1 / 10 / 20 / 30.
`attached_assets/generated_images/archi-character.png` остаётся резервным
изображением при ошибке загрузки.
