# Фотографии ARCHI

Эта папка предназначена для фотографий персонажа. Игровой экран уже подключён к этим слотам:

- `level-01.png` — стартовый образ, уровень 1+
- `level-10.png` — следующий образ, уровень 10+
- `level-20.png` — следующий образ, уровень 20+
- `level-30.png` — следующий образ, уровень 30+

Чтобы заменить текущие изображения, сохраните новые фотографии под теми же именами. Рекомендуется PNG с прозрачным фоном или квадратный JPG/PNG с персонажем по центру. Стили игры добавляют тень и аккуратно вписывают фото в карточку, не изменяя пропорции.
