# Фотографии ARCHI

Эта папка содержит отдельные игровые портреты ARCHI. Они аккуратно вырезаны
из верхнего правого ряда «СТИЛИ ПЕРСОНАЖА» файла
`A486BF40-A4CF-47A9-95B2-C52D82DA1135.png`. Исходный файл сохранён без изменений;
заголовки, подписи, рамки и остальные панели в игру не попадают.

- `level-01.png` — «Новичок», уровень 1+
- `level-10.png` — «Развитие», уровень 10+
- `level-20.png` — «Успешный», уровень 20+
- `level-30.png` — «Легенда», уровень 30+

`ArchiCharacter` выбирает эти файлы по порогам уровня 1 / 10 / 20 / 30.
`attached_assets/generated_images/archi-character.png` остаётся резервным
изображением при ошибке загрузки и доступен отдельно для главного экрана.
